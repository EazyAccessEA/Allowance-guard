Archive Source
AllowanceGuard has been retired. The scanner and API have been shut down and the browser extension is no longer supported. These articles remain as a free, archived reference. To review or revoke live wallet approvals today, use an independent, maintained tool such as Revoke.cash (a third-party service not affiliated with AllowanceGuard).
