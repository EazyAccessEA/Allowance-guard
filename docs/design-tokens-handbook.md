## Brand Principles

1. **Controlled Aggression**: Bold colour, aggressive type scale, confident whitespace. Never timid.
2. **Earned Trust**: Open-source, on-chain metrics, no fabricated testimonials. Trust through transparency.
3. **Relentless Clarity**: Dense data, clear hierarchy. If someone pauses to think, we failed.
4. **Tactile Precision**: Depth, grain, engineered layering. Surfaces feel crafted, not flat.
5. **Zero Compromise**: WCAG AA+, Core Web Vitals, keyboard-first. Aggressive design that excludes people is lazy.

## Visual Signature — The Slash

A 5-degree diagonal element that brands every page without a logo:
- **Card accents**: 3px diagonal stripe on left edge of elevated cards
- **Section dividers**: Angled clip-path replacing horizontal rules
- **Button hover**: Diagonal sweep reveal on primary buttons
- **Loading state**: Animated diagonal pulse
- **Rule**: Maximum 2 Slash elements per viewport. Restraint = impact.

## Components

| Component | States | Responsive | Animation | A11y |
|-----------|--------|------------|-----------|------|
| **Button** | default, hover, active, disabled, loading | Full-width on mobile | Slash sweep on hover (primary), scale 0.98 on press | `aria-busy` for loading, focus-visible ring |
| **Card** | default, hover, glass, glass-accent | Stack on mobile | Subtle lift on hover (3px Y), glow variant | Semantic `<article>`, focus if interactive |
| **Input** | default, focus, error, disabled | Full-width always | Border colour transition | `aria-invalid`, `aria-describedby` for errors |
| **Badge** | status (safe/warning/danger/critical), chain, risk | Truncate text on small | Fade-in on mount | Icon + label always (never colour alone) |
| **Modal** | open, closing | Bottom sheet on mobile | Slide-up mobile, scale-in desktop, backdrop fade | Focus trap, Escape close, `role="dialog"` |
| **Alert** | success, error, warning, info, toast | Full-width on mobile | Slide-in from top (toast), fade-in (inline) | `role="alert"`, auto-dismiss 5s for toasts |
| **Nav** | default, scrolled (compact), mobile-open | Hamburger < md | Backdrop blur on scroll, menu slide-in | Skip link, `aria-current` on active |
| **Table** | default, row-hover, row-selected, loading | Cards on mobile | Row highlight on hover | `<table>` semantic, sortable `aria-sort` |
| **Risk Badge** | low, medium, high, critical | Same all sizes | Pulse on critical | Icon + text always |
| **Radial Gauge** | 0–100 score | Smaller on mobile | Animated fill (700ms ease-out) | `aria-label` with score text |
| **Time Machine Toggle** | off, on (simulation mode) | Same | Border glow pulse when active | `aria-pressed`, `role="switch"` |
